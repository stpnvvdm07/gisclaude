СЛОИ cad_master — геометрия из AutoCAD (yacheiki.dxf), пересчитанная в EPSG:32637
Собрано 12.10.2026. Исходные слои проекта не изменены.

ПОЧЕМУ НОВЫЕ СЛОИ
Подоснова AutoCAD лежит в московской местной системе координат (метры, начало у 37.5 в.д. / 55.667 с.ш.).
Старые слои ячеек, building_vadim и подъездов были нарисованы по привязанному растру, а он растянут
примерно на 2.4% и повёрнут на 0.4 градуса. Отсюда расхождения 3-8 м и завышенные площади (около 5%).
Слои fences, slopesandwalls, buildings_features и полевые точки лежат в верных координатах.

СИСТЕМА КООРДИНАТ ПОДОСНОВЫ (вставить в QGIS: Настройки - Пользовательские проекции - Proj String)
+proj=tmerc +lat_0=55.66666666667 +lon_0=37.5 +k=1 +x_0=12.268 +y_0=11.964 +ellps=bessel +towgs84=316.151,78.924,589.65,-1.57273,2.69209,2.34693,8.4507 +units=m +no_defs
Сдвиг x_0, y_0 откалиброван по зданиям OSM вокруг квартала; точность посадки около 1-2 м (это точность OSM).
Между собой слои cad_master и чертёж AutoCAD совпадают точно.

КАК ИСПОЛЬЗОВАТЬ ПОДЛОЖКУ ИЗ AUTOCAD
1. QGIS -> AutoCAD: Проект - Импорт/Экспорт - Экспорт проекта в DXF, CRS = пользовательская проекция выше.
   Файл вставляется в чертёж в исходные координаты (0,0), без поворота и масштаба.
2. AutoCAD -> QGIS: перетащить DXF в QGIS и назначить слою эту же проекцию. Он ляжет на слои проекта.
3. dxf/yacheiki_clean_cad.dxf — готовые ячейки и здания уже в координатах чертежа.

ПОЛЯ cells
area_m2, perim_m              площадь и периметр
size_long, size_short         стороны минимального ограничивающего прямоугольника
size_diag                     наибольшее расстояние между вершинами
planning                      комфортная, если size_diag <= 140 и size_short >= 25
plan_100                      комфортная, если size_long <= 100 и size_short >= 25
facade_m                      длина границы, совпадающей с фасадами
fence_m, slope_m              длина границы вдоль высоких ограждений (до 2.5 м) и откосов/стенок (до 4 м)
facade_area                   сумма (длина фасада x этажность x 3 м)
makarov, vertical             facade_area / area_m2; 1.3-2 высокий, 0.6-1.3 средний, иначе низкий
iso_all, isolation            (facade_m + fence_m + slope_m) / perim_m; >=0.65 высокий, <=0.35 низкий
iso_bld, iso_bld_cl           то же только по фасадам
facades                       из чего сложен фасад: bld_id:длина x этажность
*_old                         прежние значения из слоя yacheiki1700

ПОЛЯ buildings

wear_pub / wear_calc          износ опубликованный / по кривым амортизации (середина диапазона)
wear_pct, wear_src, wear40    принятый износ (опубликованный, если есть), источник, признак >= 40%
entr_cad                      число подъездов по слою AutoCAD
cells                         номера ячеек, которые здание ограничивает
