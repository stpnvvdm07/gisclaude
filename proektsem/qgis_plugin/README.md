# Плагин QGIS «Коньково: слои проекта»

Установка: скопировать папку `konkovo_tools` в папку плагинов профиля QGIS
(«Настройки → Профили пользователей → Открыть папку активного профиля» → `python/plugins/`), перезапустить QGIS,
включить в «Модули → Управление модулями». Либо заархивировать `konkovo_tools` в zip и поставить через «Установить из ZIP».

Меню «Модули → Коньково»:
- **Обновить слои до последней версии** — все слои из `konkovo/analiz/problems_vNN.gpkg` переводятся на самую свежую версию,
  если в ней есть слой с тем же именем; стили, подписи и фильтры сохраняются.
- **Удалить ненужные слои** — показывает список и удаляет битые слои, слои устаревших версий, дубли и пустые группы.

Без QGIS: `python3 tools/clean_project.py` — переводит `proektsem.qgz` на последнюю версию данных правкой XML (остальное в проекте не меняется).
