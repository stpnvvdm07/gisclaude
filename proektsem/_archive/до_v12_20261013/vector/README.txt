konkovo.gpkg - все рабочие слои, EPSG:32637. Геометрия из чертежа dxf/yacheiki.dxf.

Проекция чертежа для QGIS (Настройки - Пользовательские проекции - Proj String):
+proj=tmerc +lat_0=55.66666666667 +lon_0=37.5 +k=1 +x_0=12.268 +y_0=11.964 +ellps=bessel +towgs84=316.151,78.924,589.65,-1.57273,2.69209,2.34693,8.4507 +units=m +no_defs

cells        показатели из tables/Подсчёты по ячейкам.xlsx; area и perimeter - по новой геометрии
buildings    поля как в tables/Таблица зданий.xlsx, ключ id = FID
green        type: деревья / трава. Деревья - кроны со спутника и массивы деревьев съёмки (радиус кроны 3.5 м)
trees        отдельные деревья из съёмки (слой 39 чертежа)
paths        пешеходные линии OSM; roads - проезды OSM
roads_tree   дерево путей по правилу задания: workload - число путей, group - группа интенсивности
